## Your Setup Checklist

### Codebases

- [ ] secretariat — <https://github.com/equanimitech/secretariat>

### MCP Servers to Activate

- [ ] secretariat — local daemon + MCP exposing compose/capture/stamp/read/channels/orgs. Install the Tauri app; `sec mcp install` wires it into Claude Code automatically.

- [ ] things-mcp — Things 3 task access (macOS). Install via plugin marketplace; requires Things 3 app.

- [ ] context7 — fetches current library docs. Add via `/plugin` or your MCP config.

- [ ] zenborg — intention-cultivation garden vault at `~/.zenborg`. Optional; install if you use the Zenborg Tauri app.

### Skills to Know About

- /idea — capture a raw product thought mid-conversation. Lands in the review queue, not in chat.

- /pain — capture a bug, friction, or improvement without fixing inline.

- /clear — reset conversation context between unrelated tasks.

- /mcp — inspect MCP server status and available tools.

- /doctor — diagnose Claude Code setup issues.

- /effort — sizing helper for upcoming work.

- /shaping — turn a captured idea into a Shape Up pitch (Boundaries / Elements / Risks / Pitch).

- /share — draft a shareable handoff doc to `~/Downloads/`.
