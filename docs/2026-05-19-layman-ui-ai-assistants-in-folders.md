# Layman UI = AI assistants in folders

- Layman version of Secretariat = AI assistants opened in specific channels
- Each channel = a normal folder where people store any type of file
- It's basically a set of focused sessions
- The "channel" abstraction maps onto something everyone already knows: a folder you cd into
- The agent that activates there = the AI assistant for that focus

- What stays? (folder, file, AI-in-this-folder)
