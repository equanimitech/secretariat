# Alternative framings for Secretariat

Exploration session 2026-05-19 — different angles for describing what Secretariat is, by audience and altitude.

## One-liners by altitude

* **Substrate:** "AI-mediated correspondence stamped by humans"

* **Product:** "Slack for humans + agents, federated and signed"

* **System:** "An append-only signed envelope log per channel, with selective human attestation"

* **Framework:** "The operating substrate for an autonomous enterprise" (the framework Marcelo's book describes — note: Marcelo is sole author, Rafa is substrate builder, not co-author)

* **Cultural:** "Software for the era when your colleagues include AI"

* **Philosophical:** "Where bounded autonomy meets human discernment"

## Metaphors

* **Court reporter for an org** — neutral, signed, contemporaneous record

* **Diplomatic pouch** — signed bytes between sovereign parties, no broker reads the contents

* **Git for organizational communication** — append-only, signed commits, channels = branches, no central authority

* **Filesystem with a memory** — files (envelopes) accumulate; some get notarized (stamped)

* **A shared brain** — humans + agents read/write same envelopes; humans bound the brain's commitments

* **Notarized timeline** — personal journal with selective Touch-ID attestations

* **Library archive with a stream** — feed AND accumulated record

* **Diary that signs itself** — every entry has provable authorship; some are notarized

* **Multiplayer Claude Code** — your project's CLAUDE.md, skills, context become shareable

* **The signed substrate under the conversation** — Slack/email is surface, this is underneath

* **The PA the founder always wished they had** — drafts everything; human stamps the moments

## Definitional angles

* It's a journal that scales to teams (solo → bilateral → org)

* It's a chat substrate where bots have signatures (only humans can stamp — biometric gate)

* It's a federation protocol for organizations (no central server, no broker, no telemetry)

* It's an event store + context store in one substrate (envelope stream + channel-dir, both markdown)

* It's a permission system without a central authority (owner-as-sequencer + roster + signed envelopes)

* It's the connective tissue between Claude Code projects (each channel-dir IS a Claude project)

## Functional handles

* "The decision ledger that drafts itself"

* "Async-first by default" — no presence, no read receipts

* "BYO-cognition, BYO-keys, BYO-relay" — sovereignty all the way down

* "Markdown all the way down" — human-readable, grep-able, portable

* "Stamps are the new email subject line" — what got stamped tells you what matters

* "Roster gates, signed envelopes, no broker" — the three primitives

## Comparisons that locate it

* Slack + git + Notion + iMessage / 4 — right shape from each, none of the central servers

* What email could have been if signed envelopes shipped in 1994

* What Slack would be if it were federated and AI-native from day one

* A personal knowledge base that scales to a team and an org

* Git, but for messages and decisions instead of code

* Notion, but where docs are also a signed event log

* Loom, but for written stamped commitments instead of video

## Three-word taglines

* Sovereign organizational substrate

* Signed, stamped, synced

* Humans bound AI

* Federated organizational memory

* Context that travels

* Decisions, not chat

* Stamps over noise

* Substrate, not Slack

## What it is NOT

* Not a SaaS — distribution is local daemon + optional self-hosted relay

* Not a chat app — selective human attention, not real-time presence

* Not a doc editor — markdown files, edit in whatever you use

* Not a project tracker — no kanban, no tickets, no statuses; just signed envelopes

* Not an AI tool — AI is a participant, not the product

* Not a knowledge base — substrate IS the knowledge, but stream + state, not a wiki

## Recursive framing

Marcelo Ballestiero (sole author) wrote *Autonomous Enterprise*. Secretariat is the operational substrate the book argues for, built by Rafa while Marcelo writes the book. The system bounds AI autonomy via human stamps; the framework about bounded autonomy is being written using bounded autonomy. The book is being written *in* Secretariat. Recursive validation, not co-authorship — the book is Marcelo's, the substrate is Rafa's.
