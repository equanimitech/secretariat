# Channel Map Navigation — Slice A (Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `OrgPicker` main-window surface with a continuously-zoomable, read-only map of orgs → channels → envelopes built on React Flow. Read-only — no editing, no Drafts panel, no Stamp surfacing (Slices B + C).

**Architecture:** New Tauri commands wrap existing `secretariat_core` channel-browse use cases. New React component `ChannelMap` renders a React Flow canvas with a custom fractal `Zone` node and a horizontal `Chain` component for envelopes. Mounts inside `MainWindowContent` where `OrgPicker` mounts today. Topographic visual idiom, continuous opacity ramp tied to viewport zoom, gesture vocabulary (hover / click / dbl-click / Esc / Cmd+arrows / breadcrumb).

**Tech Stack:** React 19, Tauri v2, React Flow (`@xyflow/react`), `dagre` for auto-tile layout, Tailwind v4, Vitest, system fonts, existing `secretariat_core` use cases (`list_orgs`, `list_channels`, `read_channel`), tauri-specta bindings.

**Spec source:** `docs/superpowers/specs/2026-05-18-channel-map-navigation-design.md`

```rust
// ---- Channel-map Slice A commands ----

#[derive(Debug, Serialize, Deserialize, specta::Type)]
pub struct ChannelTreeNode {
    /// Canonical handle, e.g. `dommage-corporel:paris-cohort`.
    pub handle: String,
    /// Display name (from channel manifest) — empty when unset.
    pub name: String,
    /// Number of envelopes in this channel.
    pub envelope_count: usize,
    /// Most recent envelope timestamp (RFC 3339), or null if unparseable.
    pub latest_at: Option<String>,
}

#[derive(Debug, Serialize, Deserialize, specta::Type)]
pub struct ChainEnvelopeSummary {
    /// Channel handle.
    pub handle: String,
    /// Absolute file path (for downstream `read_envelope` calls).
    pub file_path: String,
    /// Filename-parsed timestamp (RFC 3339), or null if unparseable.
    pub at: Option<String>,
    /// Headline — for v0.3 this is the first line of body, truncated.
    pub headline: String,
    /// True if envelope has a stamp record.
    pub stamped: bool,
    /// Placeholder — substrate has no read-tracking yet; always false.
    pub read: bool,
}

/// List channels in the principal's private (`_self`) vault.
#[tauri::command]
#[specta::specta]
pub async fn list_channel_tree() -> Result<Vec<ChannelTreeNode>, String> {
    use secretariat_core::application::list_channels;
    let paths = KeyPaths::discover().map_err(|e| format!("resolving ~/.secretariat: {e}"))?;
    let self_channels = paths.root.join("channels");
    let rows = list_channels(&self_channels)
        .map_err(|e| format!("list_channels: {e}"))?;
    Ok(rows
        .into_iter()
        .map(|r| ChannelTreeNode {
            handle: r.handle,
            name: r.name,
            envelope_count: r.envelope_count,
            latest_at: r.latest_at.map(|t| t.to_rfc3339()),
        })
        .collect())
}

/// List channels under one specific org alias.
#[tauri::command]
#[specta::specta]
pub async fn list_org_channel_tree(alias: String) -> Result<Vec<ChannelTreeNode>, String> {
    use secretariat_core::application::list_channels;
    use secretariat_core::infrastructure::org_store::org_dir;
    let paths = KeyPaths::discover().map_err(|e| format!("resolving ~/.secretariat: {e}"))?;
    let org_root = org_dir(&paths.orgs_root, &alias.parse().map_err(|e| format!("alias: {e}"))?);
    let channels_root = org_root.join("channels");
    if !channels_root.exists() {
        return Ok(Vec::new());
    }
    let rows = list_channels(&channels_root)
        .map_err(|e| format!("list_channels({alias}): {e}"))?;
    Ok(rows
        .into_iter()
        .map(|r| ChannelTreeNode {
            handle: r.handle,
            name: r.name,
            envelope_count: r.envelope_count,
            latest_at: r.latest_at.map(|t| t.to_rfc3339()),
        })
        .collect())
}

/// Return the N most-recent envelope summaries for one channel.
/// `alias` of `"_self"` reads from the private vault.
#[tauri::command]
#[specta::specta]
pub async fn read_channel_chain(
    handle: String,
    limit: usize,
) -> Result<Vec<ChainEnvelopeSummary>, String> {
    use secretariat_core::application::read_channel;
    use secretariat_core::domain::QueueHandle;
    let paths = KeyPaths::discover().map_err(|e| format!("resolving ~/.secretariat: {e}"))?;
    let channels_root = paths.root.join("channels");
    let parsed = handle
        .parse::<QueueHandle>()
        .map_err(|e| format!("handle parse: {e}"))?;
    let rows = read_channel(&channels_root, &parsed, limit.max(1).min(500))
        .map_err(|e| format!("read_channel({handle}): {e}"))?;
    Ok(rows
        .into_iter()
        .map(|env| ChainEnvelopeSummary {
            handle: handle.clone(),
            file_path: env.file_path,
            at: env.timestamp.map(|t| t.to_rfc3339()),
            headline: env
                .body
                .lines()
                .next()
                .unwrap_or("")
                .chars()
                .take(80)
                .collect(),
            stamped: env.has_stamp,
            read: false,
        })
        .collect())
}
```

```typescript
import { useEffect, useState } from 'react'
import { commands } from '@/lib/bindings'

export type ZoneKind = 'org' | 'channel' | 'envelope'

export interface ZoneData {
  id: string
  kind: ZoneKind
  /** Display headline (org name, channel handle, envelope first-line). */
  headline: string
  /** One-sentence lede; empty in Slice A (distillation deferred). */
  lede: string
  /** Most-recent activity timestamp (RFC 3339), or null. */
  latestAt: string | null
  /** Salience values (0..1). */
  unread: number
  stamped: boolean
  /** For org: alias. For channel: full handle. For envelope: file path. */
  ref: string
  /** For channels under an org: the org alias. Null for `_self`. */
  orgAlias: string | null
}

export interface EnvelopeGlyph {
  id: string
  headline: string
  at: string | null
  stamped: boolean
  read: boolean
  filePath: string
}

export function zoneIdForOrg(alias: string): string {
  return `org:${alias}`
}

export function zoneIdForChannel(orgAlias: string, handle: string): string {
  return `channel:${orgAlias}:${handle}`
}

export function zoneIdForEnvelope(filePath: string): string {
  // FNV-1a 32-bit hash — collision-resistant enough for React Flow node ids.
  let h = 2166136261
  for (let i = 0; i < filePath.length; i++) {
    h ^= filePath.charCodeAt(i)
    h = Math.imul(h, 16777619)
  }
  return `envelope:${(h >>> 0).toString(16)}`
}

export function parentZoneId(id: string): string | null {
  if (id.startsWith('org:')) return null
  if (id.startsWith('envelope:')) return null
  if (id.startsWith('channel:')) {
    const parts = id.split(':')
    // channel:<orgAlias>:<segment1>[:<segment2>...]
    if (parts.length === 3) return `org:${parts[1]}`
    return parts.slice(0, -1).join(':')
  }
  return null
}

// ---- Loader hooks ----

export function useArchipelago() {
  const [zones, setZones] = useState<ZoneData[] | null>(null)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    let cancelled = false
    void commands.listReviewableOrgs().then(res => {
      if (cancelled) return
      if (res.status === 'ok') {
        setZones(
          res.data.map(o => ({
            id: zoneIdForOrg(o.alias),
            kind: 'org' as const,
            headline: o.display_name,
            lede: '',
            latestAt: null,
            unread: 0,
            stamped: false,
            ref: o.alias,
            orgAlias: o.alias === '_self' ? null : o.alias,
          }))
        )
      } else {
        setError(res.error)
      }
    })
    return () => {
      cancelled = true
    }
  }, [])

  return { zones, error }
}

export function useChannelTree(orgAlias: string | null) {
  const [zones, setZones] = useState<ZoneData[] | null>(null)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    let cancelled = false
    const promise =
      orgAlias === null || orgAlias === '_self'
        ? commands.listChannelTree()
        : commands.listOrgChannelTree(orgAlias)
    void promise.then(res => {
      if (cancelled) return
      if (res.status === 'ok') {
        setZones(
          res.data.map(c => ({
            id: zoneIdForChannel(orgAlias ?? '_self', c.handle),
            kind: 'channel' as const,
            headline: c.name || c.handle,
            lede: '',
            latestAt: c.latest_at,
            unread: 0,
            stamped: false,
            ref: c.handle,
            orgAlias,
          }))
        )
      } else {
        setError(res.error)
      }
    })
    return () => {
      cancelled = true
    }
  }, [orgAlias])

  return { zones, error }
}

export function useChannelChain(handle: string | null, limit = 50) {
  const [chain, setChain] = useState<EnvelopeGlyph[] | null>(null)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    if (handle === null) {
      setChain(null)
      return
    }
    let cancelled = false
    void commands.readChannelChain(handle, limit).then(res => {
      if (cancelled) return
      if (res.status === 'ok') {
        setChain(
          res.data.map(e => ({
            id: zoneIdForEnvelope(e.file_path),
            headline: e.headline,
            at: e.at,
            stamped: e.stamped,
            read: e.read,
            filePath: e.file_path,
          }))
        )
      } else {
        setError(res.error)
      }
    })
    return () => {
      cancelled = true
    }
  }, [handle, limit])

  return { chain, error }
}
```

```tsx
import { Handle, Position, useStore } from '@xyflow/react'
import { type NodeProps } from '@xyflow/react'
import type { ZoneData } from './zone-data'

/** Linear ramp clamped to [0, 1]. */
function ramp(value: number, start: number, end: number): number {
  if (value <= start) return 0
  if (value >= end) return 1
  return (value - start) / (end - start)
}

export function ledeOpacity(zoom: number): number {
  return ramp(zoom, 0.35, 0.65)
}

export function bodyOpacity(zoom: number): number {
  return ramp(zoom, 0.65, 0.9)
}

const selectZoom = (state: { transform: [number, number, number] }) =>
  state.transform[2]

export function ZoneNode({ data, selected }: NodeProps<{ data: ZoneData }>) {
  const zoom = useStore(selectZoom)
  const lede = ledeOpacity(zoom)
  const body = bodyOpacity(zoom)
  const kindClass =
    data.kind === 'org'
      ? 'zone-org'
      : data.kind === 'channel'
        ? 'zone-channel'
        : 'zone-envelope'

  return (
    <div
      className={`zone ${kindClass} ${selected ? 'zone-selected' : ''} ${
        data.stamped ? 'zone-stamped' : ''
      }`}
    >
      <Handle type="target" position={Position.Top} style={{ opacity: 0 }} />
      <Handle type="source" position={Position.Bottom} style={{ opacity: 0 }} />
```

```typescript
import dagre from 'dagre'

const NODE_W = 180
const NODE_H = 90

export interface LayoutInput {
  id: string
  headline: string
}

export interface PositionedNode {
  id: string
  position: { x: number; y: number }
}

/**
 * Lays out a set of zones in a responsive auto-tile grid using dagre.
 * Deterministic for a given input order — but order is NOT stable across
 * filesystem mutations. For Slice A this is acceptable; stable positions
 * are a Task for Slice B+ when we layer in branch-at-timestamp.
 */
export function autoTile(nodes: LayoutInput[]): PositionedNode[] {
  if (nodes.length === 0) return []
  const g = new dagre.graphlib.Graph()
  g.setDefaultEdgeLabel(() => ({}))
  g.setGraph({ rankdir: 'TB', nodesep: 40, ranksep: 60 })

  for (const n of nodes) {
    g.setNode(n.id, { width: NODE_W, height: NODE_H })
  }
  // No edges — dagre will still place nodes in a grid based on rank/sep.
  dagre.layout(g)

  return nodes.map(n => {
    const pos = g.node(n.id)
    return {
      id: n.id,
      position: { x: pos.x - NODE_W / 2, y: pos.y - NODE_H / 2 },
    }
  })
}
```

```typescript
/**
 * Glow intensity for unread/unaddressed Zones.
 *
 * Decay is f(arrival_age, read_status):
 *  - read=true → glow = 0 immediately
 *  - read=false → exponential decay; ~14-day half-life-ish; floors to 0 at 30 days
 *
 * Per BCT review: prevents perpetual ambient anxiety on neglected Zones.
 */
export function glowIntensity(input: {
  ageSeconds: number
  read: boolean
}): number {
  if (input.read) return 0
  const DAY = 86400
  const ageDays = input.ageSeconds / DAY
  if (ageDays >= 30) return 0
  // Exponential decay reaching ~0.135 at 14 days.
  return Math.exp(-ageDays / 7)
}
```

```tsx
import { glowIntensity } from './glow'
import type { EnvelopeGlyph } from './zone-data'

interface ChainProps {
  glyphs: EnvelopeGlyph[]
  /** Optional callback when user clicks a glyph. */
  onGlyphClick?: (glyph: EnvelopeGlyph) => void
}

const NOW = () => Date.now() / 1000

function ageSeconds(at: string | null): number {
  if (!at) return Number.POSITIVE_INFINITY
  const t = Date.parse(at) / 1000
  return Math.max(0, NOW() - t)
}

export function Chain({ glyphs, onGlyphClick }: ChainProps) {
  if (glyphs.length === 0) {
    return <div className="chain-empty">No envelopes yet.</div>
  }

  // Oldest-left, recent-right.
  const sorted = [...glyphs].sort((a, b) => {
    const at = Date.parse(a.at ?? '') || 0
    const bt = Date.parse(b.at ?? '') || 0
    return at - bt
  })

  return (
    <div className="chain">
      <div className="chain-rail" />
      <div className="chain-glyphs">
        {sorted.map(g => {
          const glow = glowIntensity({
            ageSeconds: ageSeconds(g.at),
            read: g.read,
          })
          return (
            <button
              key={g.id}
              type="button"
              title={`${g.headline} · ${g.at ?? 'no timestamp'}`}
              data-testid="chain-glyph"
              className={`chain-glyph ${g.stamped ? 'chain-glyph-stamped' : ''}`}
              style={{
                boxShadow:
                  glow > 0
                    ? `0 0 ${4 + glow * 8}px rgba(212, 132, 42, ${glow * 0.7})`
                    : 'none',
              }}
              onClick={() => onGlyphClick?.(g)}
            >
              <span className="chain-glyph-dot" />
            </button>
          )
        })}
      </div>
    </div>
  )
}
```

- [ ] **Step 5: Add keymap (Esc + Cmd+arrows)**

Create `src/components/channel-map/keymap.ts`:

```typescript
import { useEffect } from 'react'

export interface KeymapHandlers {
  onEscape: () => void
  onSiblingLeft?: () => void
  onSiblingRight?: () => void
  onSiblingUp?: () => void
  onSiblingDown?: () => void
}

export function useMapKeymap(h: KeymapHandlers) {
  useEffect(() => {
    function handler(e: KeyboardEvent) {
      if (e.key === 'Escape') {
        h.onEscape()
        return
      }
      if (!(e.metaKey || e.ctrlKey)) return
      switch (e.key) {
        case 'ArrowLeft':
          h.onSiblingLeft?.()
          break
        case 'ArrowRight':
          h.onSiblingRight?.()
          break
        case 'ArrowUp':
          h.onSiblingUp?.()
          break
        case 'ArrowDown':
          h.onSiblingDown?.()
          break
        default:
          return
      }
      e.preventDefault()
    }
    window.addEventListener('keydown', handler)
    return () => window.removeEventListener('keydown', handler)
  }, [h])
}
```
